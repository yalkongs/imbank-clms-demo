# AGY CLI 독립 은행 요구기능 평가

> 실행일: 2026-08-11 (Asia/Seoul)  
> 실행 방식: `agy --print-timeout 10m --print <검증 패킷>`  
> 종료 상태: exit code 0  
> 용도: CLMS 추가 요구기능 우선순위의 독립 교차검토

이 문서는 AGY CLI의 입력 요약과 원문 출력을 함께 보존한다. AGY 의견은 법령·감독규정의 1차 근거가 아니며, 현재 코드 사실과 규제 적용성은 [은행 요구기능 갭 연구](../docs/BANK_REQUIRED_CAPABILITIES_RESEARCH_2026-08-11.md)에서 별도로 검증했다.

## 입력 패킷

AGY에는 파일·도구 접근 없이 아래 검증사실만 사용하고, 명시의무·감독목표·실무권고를 구분하도록 지시했다.

- 기준일 2026-08-11, 분석 PoC, 사용자 화면 37, OpenAPI 242 paths/243 operations, 업무 테이블 95, 시험 171 passed/1 skipped
- 신청금액 기준 전결권, 승인조건 컬럼, 인증 사용자 기반 승인, 승인·한도예약·스냅샷·핵심감사 트랜잭션은 구현
- 임의 단계전이와 즉시 최종승인, 조건부 승인 후 ID 충돌, 위원회·정족수·회피·위임 부재
- 전역 쓰기 인증만 존재하며 일반 사용자의 client-supplied actor waiver와 `FREEZE_LIMIT` 실행 가능
- 승인조건 실사용 0건, 구조화 CP/CS·증빙·waiver 부재
- 계정계 booking/outbox/멱등성/callback/retry/reconciliation 및 거래 반영형 익스포저 원장 부재
- 신규 신청액을 합산하지 않는 스냅샷 그룹한도, KYC/KYB/UBO/CDD/EDD 및 EDMS·담보권 gate 부재
- RAROC 허들 10/12/14/15% 혼재, 감사 시점·IP·실패처리 공백, DB 경로·마이그레이션 및 CI 공백
- iM 시중은행 전환의 전국·관계형금융·지역공급·내부통제 보고 특성
- KoFIU CDD, 책무구조도, 독립 여신감리/EWS 검증, 2026 대출금리 법적비용 규율에 관한 공식 확인사실

출력 형식은 1,200자 이내 한국어 Markdown의 `판정`, `P0`, `P1/P2`, `시스템 경계`, `파일럿 인수기준` 5개 절로 제한했다.

## AGY 원문 출력

### 1) 판정

**상용 운영 불가 (Unsuitable for Production)**  
전결권 계산 및 트랜잭션 묶음 PoC는 구현되었으나, FSM 임의 점프, RBAC/ABAC 부재, CDD/UBO 연계 부재, 계정계 원장 갱신 미비로 법령상 명시의무(KoFIU, 지배구조법) 및 감독상 통제목표를 충족하지 못함.

### 2) P0

- **FSM 및 승인 통제**: RECEIVED→APPROVED 즉시 승인 및 단계 임의 점프 차단. CONDITIONAL 재결재 500 에러 수정, 정족수/회피/위임 로직 구현. (감독상 통제)
- **RBAC/ABAC 도입**: STAFF가 client-supplied `approved_by`로 Waiver 승인 및 FREEZE_LIMIT 실행 가능한 보안 결함 차단. (감독상 통제)
- **AML(CDD/EDD/UBO) 연계 Gate**: 대출 신청 시 실제소유자, 거래목적, 자금원천 검증 미완료 건의 승인/실행 차단. (KoFIU 명시의무)
- **대출금리 산정 통제**: 2026-07-01 시행 금리 내 법적비용 반영 제한 및 연 2회 자체점검 이력 반영. (법령/감독 의무)

### 3) P1/P2

- **P1**: 계정계 Booking 연계(Outbox/멱등성/원장 실시간 갱신), 스냅샷 그룹한도 신규 신청액 합산, RAROC 허들(10~15%) 일원화, EDMS/전자서명/담보 완성 Gate. (실무 권고)
- **P2**: 감사로그 표준화(UTC, 실IP, 감사실패 시 차단), DB 마이그레이션 실패 시 Fail-Fast 적용, CI 테스트 확장. (실무 권고)

### 4) CLMS 직접소유와 외부연계 경계

- **CLMS 직접소유**: 여신 신청/심사 FSM, 전결권·한도 검증, RAROC 산출, 조건(Covenant) 및 심사 이력 관리.
- **외부 연계 (API)**: 계정계(Booking/원장), 은행 공통 AML/CDD/UBO 모듈, EDMS/전자서명, 외부 신용·담보평가.  
  *(주의: 특정 UI나 기술 스택은 법적 강제 사항이 아니므로 API 기반으로 결합도를 낮춤)*

### 5) 파일럿 인수기준

1. FSM 무단 점프 0건 및 RBAC 우회 통한 Waiver/제재 실행 차단.
2. CONDITIONAL 재결재 포함 트랜잭션 오류(500) 0건.
3. AML CDD/UBO 미이행 건의 대출 승인·실행 자동 차단.
4. 계정계 연계 멱등성 보장 및 승인 시 신용공여원장·그룹한도 합산 반영 100%.
5. DB 마이그레이션 실패 시 서비스 기동 차단 및 감사로그(UTC/실IP) 정상 저장.

## 활용 시 주의

AGY는 감사로그·마이그레이션·CI를 P2로 분류했지만, 실제 은행 운영 전환에서는 보안·감사·복구 요구에 따라 더 앞당겨질 수 있다. 최종 우선순위와 규제 해석은 현재 코드 실증과 공식 근거를 함께 둔 본 프로젝트의 은행 요구기능 갭 연구를 따른다.
