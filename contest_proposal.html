CLMS 기업여신 생애주기 통합관리 플랫폼
심사 · 실행 · 모니터링 · 회수를 하나의 데이터 흐름으로 — Credit Lifecycle Management System

1. 제안 배경

  • 기업여신 업무가 심사 · 사후관리 · 담보 · 부실관리로 분절되어, 같은 차주의 등급·담보·연체 정보가 서로 다른 주기와 도구로 관리된다.
  • 위험 신호가 연체 발생 이후에야 인지되고, 담보 재평가는 수기 주기에 의존해 LTV 악화를 제때 알기 어렵다.
  • 여신 금리가 관행과 경쟁 상황으로 결정되어 리스크 대비 수익(RAROC)이 건별로 측정되지 않는다.

2. 핵심 기능 — 고품질 3대 엔진

PRICING

RAROC 기반 금리산출

기준금리 · FTP · 신용스프레드(EL+UL) · 경비율 · 목표마진을 구성요소별로 분해해 산출하고 산업전략·담보 가감을 자동 반영한다. 허들레이트 대비 RAROC을 즉시 판정해 수익성 미달 여신을 승인 전에 걸러낸다.

금리산출 1,200건 · 16단계 등급체계 · PD/LGD/RWA 연동
EWS

다중신호 조기경보

재무 · 거래행태 · 공급망 · 공시/등기 · 뉴스감성 · 시장신호를 상시 스코어링해 종합점수로 통합한다. 부도거리·CDS·내재PD까지 읽어 연체 이전에 부실 징후를 선행 포착한다.

지표값 36,000건 · 뉴스감성 22,435건 · 공급망 35,952건 · 거래행태 12,120건
COLLATERAL

담보 이력관리·LTV

담보별 감정평가 이력을 시계열로 축적하고 부동산가격지수에 연동해 자동 재평가한다. LTV 임계 초과·담보가치 급락 시 경보를 자동 생성해 보강 요구 시점을 놓치지 않는다.

담보 1,110건 · 재평가 이력 6,660건 · 자동 경보 1,663건 · 지수 1,440건

4. 구현 현황

  • 화면 20종 · API 25개 라우터 · DB 80개 테이블로 여신 전 생애주기를 단일 데이터 모델 위에 구현했다.
  • 여신심사(재무분석·그룹여신·코버넌트), 부실관리(건전성분류·ECL·연체), 자동화, ESG·ALM·스트레스테스트까지 실제 동작하는 화면으로 완비.
  • 고객 1,010사 · 여신신청 1,260건 · 약정 1,200건 · 코버넌트 점검 6,802건 규모의 데이터로 즉시 시연 가능.

5. 차별점 · 확장 계획

아이디어가 아니라 돌아가는 시스템. React 18 + FastAPI 단일 배포 구조로 브라우저에서 바로 시연된다.
감독규정 반영. 자산건전성 분류기준과 IFRS9 ECL 산식을 코드에 내장했다.
파일럿 전환. 행내 여신·담보·거래 데이터를 연결하면 그대로 현업 파일럿으로 확장할 수 있다.

현재 CLMS의 EWS는 지표 기반 종합점수 방식이다. 여기에 대량 데이터로 학습한 부도예측 모델을 결합해 규칙 기반 스코어링을 학습 기반 예측으로 전환한다. 타깃 누수 제거 · 재현성 검증 · 학습/서빙 정합성 확보까지 완료했으며, 행내 실데이터를 연결하면 기간별 재보정과 순위 기반 알림 정책으로 확장해 현업이 실제로 처리 가능한 분량의 정밀 경보를 제공한다.
