## B. 데이터 충분성 — codex 판단("설명용 PoC 일부 충분, 가중치 승인 근거 불충분") 채택

- 실측: 카드매출 이벤트 표본 **8사**(적격∩이벤트 교집합), 시장신호 25사/탐지 1건 — Wilson 95% CI 가 61~100% 수준으로 넓음. 고용·B2B 91사는 서술 가능.
- 자기충족성: 신규 채널 100% 탐지는 생성 규칙의 재확인이지 검증이 아님 — codex 지적 타당.
- **조치**: ① 검증 화면에 채널별 이벤트/대조군 표본·Wilson 95% CI·`표본부족` 배지 표시 ② **합성 데모 상시 고지** 배너 ③ 합성 근거인 동안 가중치 발효에 `synthetic_ack` 승인자 확인 강제(미확인 422) ④ README '실측' 표현 정정. 실데이터 전환 시 필요 요소(사건일 원장·관측/입수/적재 시점·동의 이력화·검열 처리 등)는 codex 목록을 본 문서에 계승.

## C. 화면 효율성 — "평면 10탭은 더 이상 유효하지 않다" 채택

- **조치**: codex 권고안 1(난도 낮음) 구현 — 1차 그룹 4개(`개요 | 채널 모니터링 | 검증·거버넌스 | 조치`) + 채널 7종은 2차 필 탭. `activeTab` 단일 상태 유지로 기존 로직 무변경.
- 부수 지적 반영: 통합 대시보드에 신규 3채널 평균·커버리지 표시(8채널 바), 방법론 모달의 5/6채널·구 가중치 설명을 정본(규정 레지스터·재정규화·백테스트 거버넌스) 기준으로 갱신, 전역 지역 필터는 미지원 탭에서 숨김.

## 데이터 충분성 개선 ① (당일 후속 구현)
